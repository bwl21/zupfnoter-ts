# Zupfnoter Phase 5 – Snapshot 5.2 Agent Ready

Dieses Paket enthält die verdichteten Ergebnisse des Phase-5-Workshops nach dem vereinbarten leichten Schema.

Pro Thema gibt es:

```text
01_thema.md        Menschliches Wissensdokument
02_agent_prompt.md Vollständiger eigenständiger Agentenauftrag
```

Es gibt bewusst keine Requirement-IDs. Traceability entsteht über:

```text
Commit
  -> Thema
  -> Implementierungsauftrag im 01_thema.md
  -> Agent Prompt
  -> Diskussion/Entscheidung
```

## Empfohlene Nutzung

1. `00-roadmap/phase-5-umsetzungsstrategie.md` lesen.
2. Mit `17-design-system-basiskomponenten/02_agent_prompt.md` beginnen.
3. Nach Agentenlauf `17-design-system-basiskomponenten/01_thema.md` Status aktualisieren.
4. Danach schrittweise weitere Themen bearbeiten.

## Lokales Rohmaterial

Der vollständige Rohthread sollte lokal unter `000_raw/` aufbewahrt werden, aber nicht ins öffentliche Repository gepusht werden.
