# Promotion und Video-Produktion

Dieses Verzeichnis enthält die redaktionelle und fachliche Grundlage für die
Promotion- und Schulungsmedien von Zupfnoter-ts.

## Dokumente

- [`kommunikationsgrundlage-zupfnoter-ts.md`](kommunikationsgrundlage-zupfnoter-ts.md)
  ist die gemeinsame Quelle für Botschaften, Zielgruppe und Sprechertexte.
- [`video-szenen-architektur.md`](video-szenen-architektur.md) beschreibt die
  wiederverwendbare Szenenbibliothek und die Ablage der Medienartefakte.
- [`video-promotion-legacy-anwender.md`](video-promotion-legacy-anwender.md)
  enthält das ausführliche Drehbuch für das erste Promotion-Video.

Freigegebene Filme, die in der Anwendung ausgeliefert werden, gehören als
Produktassets nach `apps/web/public/media/videos/`. Rohaufnahmen und
Schnittprojekte gehören nicht in dieses Dokumentationsverzeichnis.
